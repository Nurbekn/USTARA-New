# Hairstyle catalog images

Generated with the built-in imagegen tool. These are fictional hairstyle inspiration images, not barber portfolio photographs. The visible UI retains its generated-image caption.

Files:
- `public/images/haircuts-short.webp`: buzz cut, French crop, curly taper.
- `public/images/haircuts-long.webp`: quiff, curtains, modern mullet.

Each square atlas contains three equal rows (styles) and three equal columns (front, left side, back). Saved at 1254 × 1254, WebP quality 88. Original generated files were retained outside the project; the app uses the local WebP files only.

## Prompt: short hairstyles

Use case: photorealistic-natural. Asset type: production hairstyle catalog atlas for an Uzbek booking app. Generate ONE perfectly square 1536x1536 image arranged as an EXACT edge-to-edge 3 COLUMN by 3 ROW grid of 9 equally sized square studio photographs, no gutters, no borders, no text. Each row shows the SAME handsome adult Central Asian male model with the SAME haircut, consistent clothing and haircut length from FRONT (column 1), LEFT SIDE PROFILE (column 2), BACK OF HEAD (column 3). Row 1: stylish very short BUZZ CUT with clean mid skin fade, visible uniform short hair on top. Row 2: FRENCH CROP with textured short top and distinct straight fringe, clean low fade sides. Row 3: CURLY TAPER with beautiful natural dark curls, medium-length curly top and subtle taper at temples and nape. Different adult model per row, consistent model across each row. Frame full head and upper shoulders with generous room around the hair, head centered in each square with all hair visible and the same apparent size, black plain barber cape, dark neutral charcoal studio background in every cell. Beautiful premium editorial grooming photography, highly realistic individual strands and skin texture, crisp lighting that clearly separates dark hair from background, attractive professional styling. This is a cut-and-crop sprite atlas: rows and columns must be exact equal thirds; no montage effects, no labels, no logos. Save as a project asset, not a poster.
